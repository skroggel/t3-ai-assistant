..  _installation:

Installation
============

Install the extension as a TYPO3 extension in a TYPO3 v13 project. Composer is
recommended.

..  code-block:: bash

    composer require madj2k/ai-assistant

After installation:

#. run database schema updates;
#. import the default setup if desired;
#. create connection records;
#. configure indexers;
#. run indexing;
#. add the frontend integration.

Documentation rendering
-----------------------

The documentation follows the TYPO3 documentation rendering structure with a
``Documentation/Index.rst`` entry point and ``Documentation/guides.xml``.
