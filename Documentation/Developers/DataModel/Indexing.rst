..  _data-indexing:

Indexing records
================

Indexer configuration
    Defines source type, indexer, adapter, connector, collection, connections,
    chunking settings and source-specific options.

Indexer run
    Stores counters and status for one indexing execution.

Indexer source
    Tracks source identity, content checksums, collection, vector store scope,
    file or page metadata and error state.

External connector configuration
    Stores external API configuration where a connector-based source requires it.
