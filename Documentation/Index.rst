============
AI Assistant
============

:Extension key:
    ai_assistant

:Package name:
    madj2k/ai-assistant

:Namespace:
    Madj2k\AiAssistant

:License:
    GPL-2.0-or-later

:TYPO3:
    TYPO3 v13 LTS

AI Assistant provides configurable AI assistants for TYPO3. It combines assistant
profiles, individually configurable processing pipelines, indexing of TYPO3 and
external content, vector-based retrieval and traceable answer generation.

The documentation is intended for two main audiences:

* editors, administrators and integrators who configure assistants and data
  sources in TYPO3;
* developers who extend the assistant, indexing, connection and pipeline systems.
