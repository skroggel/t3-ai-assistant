Default configurations
======================

The extension may provide default records through TYPO3 extension imports. These
records are intended as a baseline for testing and project-specific adaptation.

What defaults can provide
-------------------------

* example assistant profile;
* example pipeline steps;
* baseline prompts;
* default retrieval settings;
* example indexer configurations.

What defaults cannot provide
----------------------------

* provider API credentials;
* project-specific vector endpoints;
* final collection strategy;
* production-safe prompts for every use case;
* complete source configuration for custom data.

Review imported records before production use.
