Pipeline export
===============

The **Pipeline export** backend tab creates an AI-readable Markdown document
for an assistant profile. It is intended for reviewing and optimizing prompts
and pipeline behavior with another AI system.

The export includes global prompts, pipeline step order and types, include
settings, step prompts, runtime settings, retrieval identifiers and filters,
selector contracts and effective UI component definitions.

Provider credentials and secrets are not exported. Select a profile and use
**Start export** to download ``assistant-pipeline.md``.
